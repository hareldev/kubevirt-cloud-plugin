Number of extra VM provisioning tries after the first failure, before failing any build whose assigned label is satisfied by this template's labels.

  • 1 (default) — retry once, then cancel queued builds (2 attempts total).
  • 0 — no retries; fail the build after the first provisioning failure.
  • -1 — unlimited retries (not recommended).

The counter resets when an agent for this label comes online successfully. Each failed launch (provisioning timeout, SSH failure, etc.) counts as one attempt.
