The PVC access mode for the VM's root disk.

  • ReadWriteMany (RWX) - The disk can be mounted by multiple nodes simultaneously. This is required for live migration support. Use this if your storage backend supports RWX (e.g., Ceph RBD with appropriate configuration, NFS, or OpenShift Data Foundation).
  • ReadWriteOnce (RWO) - The disk can only be mounted by a single node at a time. Use this if your storage doesn't support RWX. Live migration will not be available.

Default: ReadWriteMany (RWX) for live migration support.
