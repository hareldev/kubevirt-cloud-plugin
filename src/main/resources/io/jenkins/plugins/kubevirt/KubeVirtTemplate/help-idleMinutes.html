The number of minutes the VM agent will remain idle before being automatically terminated. The idle timer resets each time a new build starts on this agent.

Special Values:

  • 0 - The VM will be disposed immediately after the first build completes (single-use agent).
  • 10 (default) - The VM stays alive for 10 minutes after becoming idle, allowing it to be reused for subsequent builds.

Recommendations:

  • Use 0 for builds that require a clean environment each time or to minimize resource usage.
  • Use a higher value (e.g., 30 or 60) if you have frequent builds that can reuse the same VM to avoid repeated provisioning overhead.

Examples: 0, 5, 10, 30, 60

Default: 10
