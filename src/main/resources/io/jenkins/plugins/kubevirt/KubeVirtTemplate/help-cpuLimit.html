CPU Limit - The maximum CPU the VM can use.

This caps the CPU usage of the VM. The VM will be throttled if it tries to use more than this amount. Leave empty for no limit (VM can burst to use all available CPU).

Format:

  • Integer cores: 1, 2, 4
  • Millicores: 500m, 1500m, 2000m

Examples:

  • 2 = Maximum 2 CPU cores
  • 1500m = Maximum 1.5 CPU cores
  • 4 = Maximum 4 CPU cores

Default: Empty (no limit)

Note: CPU Limit must be greater than or equal to Reserved CPU.
