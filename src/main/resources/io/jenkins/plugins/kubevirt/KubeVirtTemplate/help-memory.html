Reserved Memory - The guaranteed memory allocation for the VM.

This is the minimum memory that will be reserved for the VM. Kubernetes guarantees this amount will always be available to the VM.

Use Kubernetes quantity format with suffixes like Gi (gibibytes) or Mi (mebibytes).

Examples: 2Gi, 4Gi, 8Gi, 512Mi

Default: 2Gi

Tip: Java-based builds typically need at least 2Gi. Large Maven/Gradle projects may need 4Gi or more.

Note: Reserved Memory must be less than or equal to Memory Limit (if set).
