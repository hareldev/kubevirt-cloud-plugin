Maximum time (in minutes) to wait for the VM to become ready and obtain an IP address.

This timeout covers the entire VM provisioning process, including:

  • DataVolume cloning/import from the source disk
  • VM scheduling and starting
  • Guest agent startup and IP address assignment

Default: 15 minutes

When to increase:

  • If disk cloning takes longer due to large disk sizes
  • If storage performance is slow
  • If the network/DHCP takes longer to assign an IP
  • If the guest agent takes time to start

Note: If provisioning consistently times out, check the diagnostic messages in the Jenkins log for specific issues (storage problems, missing guest agent, etc.).
