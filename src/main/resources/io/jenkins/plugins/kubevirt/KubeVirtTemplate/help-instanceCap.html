Maximum number of concurrent VMs that can be provisioned for this specific template. This is a per-template limit that restricts how many agents can run from this template simultaneously.

Special Values:

  • 0 - Unlimited. No per-template cap is enforced.
  • 10 (default) - Up to 10 VMs can run simultaneously for this template.

Behavior:

  • When the limit is reached, new builds requiring this template will wait in the Jenkins queue.
  • Both the global VM Count Cap and per-template Instance Cap must be satisfied for a VM to be provisioned.
  • Running and provisioning VMs are counted toward this limit.

Examples: 0, 1, 5, 10, 20

Default: 10
