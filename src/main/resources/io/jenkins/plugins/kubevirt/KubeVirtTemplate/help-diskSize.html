The size of the VM's root disk. For DataSource, this must be at least as large as the source. For ContainerDisk, this determines the size of the persistent volume created from the container image.

Use Kubernetes quantity format with suffixes like Gi (gibibytes) or Ti (tebibytes).

Examples: 30Gi, 50Gi, 100Gi

Default: 30Gi

Note: The disk is provisioned using a DataVolume, which imports the container image or clones the DataSource into a PersistentVolumeClaim of the specified size.
