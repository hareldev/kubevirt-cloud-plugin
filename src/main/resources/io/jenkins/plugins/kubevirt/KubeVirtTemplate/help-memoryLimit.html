Memory Limit - The maximum memory the VM can use.

This caps the memory usage of the VM. If the VM tries to allocate more memory than this limit, processes may be terminated (OOM killed). Leave empty for no limit.

Use Kubernetes quantity format with suffixes like Gi (gibibytes) or Mi (mebibytes).

Examples: 4Gi, 8Gi, 16Gi

Default: Empty (no limit)

Tip: For predictable behavior, set the memory limit equal to reserved memory. This creates a "Guaranteed" QoS class in Kubernetes.

Note: Memory Limit must be greater than or equal to Reserved Memory.
