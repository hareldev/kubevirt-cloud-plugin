Path to the Java executable on the VM. Leave empty to use the java command from the system PATH.

Examples:

  • /usr/bin/java
  • /usr/lib/jvm/java-17-openjdk/bin/java
  • /opt/java/bin/java

Note: The Jenkins agent requires Java 11 or newer to be available on the VM. You can install Java via cloud-init or pre-install it in your VM image.
