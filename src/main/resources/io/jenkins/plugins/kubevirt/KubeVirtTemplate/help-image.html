The container image containing the VM disk. This image should be a KubeVirt ContainerDisk image with the OS disk embedded.

Examples:

  • quay.io/containerdisks/fedora:40
  • quay.io/containerdisks/centos-stream:9
  • registry.example.com/my-custom-image:latest

Note: The image must have cloud-init installed for SSH key injection to work.
