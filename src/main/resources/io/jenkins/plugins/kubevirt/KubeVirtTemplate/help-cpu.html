Reserved CPU - The guaranteed CPU allocation for the VM.

This is the minimum CPU that will be reserved for the VM. Kubernetes guarantees this amount will always be available to the VM.

Format:

  • Integer cores: 1, 2, 4
  • Millicores: 500m, 1500m, 2000m

Examples:

  • 1 = 1 full CPU core (equivalent to 1000m)
  • 500m = Half a CPU core
  • 2 = 2 CPU cores
  • 1500m = 1.5 CPU cores

Default: 1

Note: Reserved CPU must be less than or equal to CPU Limit (if set).
