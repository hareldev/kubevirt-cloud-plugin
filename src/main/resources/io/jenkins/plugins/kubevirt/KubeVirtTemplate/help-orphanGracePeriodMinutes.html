The number of minutes a VM must exist without a registered Jenkins agent before being considered orphaned and automatically deleted.

Purpose:

A background cleanup job runs periodically to detect orphaned VMs - VMs that exist in Kubernetes but have no corresponding registered agent in Jenkins. This can happen when:

  • Agent registration failed after VM creation
  • Jenkins crashed or restarted during provisioning
  • Network issues prevented proper cleanup
  • The agent termination callback failed to delete the VM

The grace period prevents deleting VMs that are still starting up and have not yet registered their agent with Jenkins.

Recommendations:

  • Use 30 (default) for most environments.
  • Increase if your VMs take longer to boot and register (e.g., large disk clones, slow cloud-init).
  • Decrease if you want faster cleanup of orphaned VMs, but ensure it's longer than your typical VM startup time.

Examples: 15, 30, 60, 120

Default: 30
