Maximum time (in seconds) to wait for cloud-init to complete SSH setup before Jenkins attempts to connect to the VM.

This applies to virtctl SSH connection type only. The plugin polls the SSH port through the Kubernetes API tunnel until sshd responds or this timeout is reached.

Default: 180 seconds (3 minutes)

When to increase:

  • Cloud-init installs many packages on first boot
  • Your cloud-init runcmd scripts take a long time to complete
  • You delay starting sshd until late in the cloud-init process

Tip: Rather than adding a long sleep in cloud-init, use bootcmd to stop sshd early and start it as the last runcmd entry. Increase this timeout only if cloud-init genuinely needs more time to finish setup.
