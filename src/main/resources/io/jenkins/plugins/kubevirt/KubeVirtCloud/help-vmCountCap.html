Maximum number of concurrent VMs that can be provisioned across all templates in this cloud. This is a global limit that applies to the entire cloud configuration.

Special Values:

  • 0 - Unlimited. No global cap is enforced.
  • 10 (default) - Up to 10 VMs can run simultaneously across all templates.

Behavior:

  • When the limit is reached, new builds will wait in the Jenkins queue until a VM becomes available.
  • Both the global VM Count Cap and per-template Instance Cap must be satisfied for a VM to be provisioned.
  • Running and provisioning VMs are counted toward this limit.

Examples: 0, 5, 10, 20

Default: 10
