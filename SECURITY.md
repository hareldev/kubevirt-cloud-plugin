# Security Policy

## Supported Versions

Security fixes are published for releases distributed through the [Jenkins Update Center](https://plugins.jenkins.io/kubevirt-cloud/). Install the latest release when possible.

## Reporting a Vulnerability

**Do not report security vulnerabilities in public GitHub issues.**

Follow the Jenkins project reporting process:

- [Reporting security vulnerabilities](https://www.jenkins.io/security/reporting/)
- File an issue in the **Jenkins Jira** [SECURITY project](https://issues.jenkins.io/secure/CreateIssue!default.jspa), using the **specific-plugin** component and naming this plugin (`kubevirt-cloud` / KubeVirt Cloud) in the summary.

If you cannot use Jira, you may email the private Jenkins Security Team mailing list: `jenkinsci-cert@googlegroups.com`.

The Jenkins security team coordinates with plugin maintainers on fixes and advisories. Please respect coordinated disclosure deadlines when applicable.
